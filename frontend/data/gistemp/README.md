# NASA GISTEMP global temperature anomalies

`GLB.Ts+dSST.csv` is the monthly global land-ocean temperature index (anomalies in °C
relative to the 1951-1980 mean), as published by the NASA Goddard Institute for Space
Studies: https://data.giss.nasa.gov/gistemp/ ("Global-mean monthly, seasonal, and annual
means", Land-Ocean Temperature Index, CSV). Downloaded on 2026-04-05.

Used by `visualizations/climate_cascade/index.qmd`.
