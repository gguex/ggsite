# Swiss data

- `cantons.csv`: one row per canton with its English and local names, abbreviation,
  capital, resident population (Federal Statistical Office, provisional figures at
  31.12.2025), area in km², official languages, year of joining the Confederation,
  half-canton flag, flag file name and a short portrait. Used by
  `visualizations/swiss_cantons/`.
- `swiss_health_premiums.csv`: average monthly premium of the mandatory basic health
  insurance per canton and year, 2014-2024, in CHF. Used by
  `visualizations/swiss_health_ojs/`.

The cantonal flags in `assets/swiss_flags/` come from Wikimedia Commons (public domain).
